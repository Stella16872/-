# 工具箱 · 使用说明

在自己 Mac 上运行的小工具，界面在浏览器里。顶上有四个标签：

| 工具 | 做什么 |
|---|---|
| **群发邮件** | 一个模板 + 一张名单，给每个人发一封带自己信息的邮件，可以带附件（每人一份也行） |
| **合并表格** | 几张表上下拼成一张，比如各部门交上来的表 |
| **拆分表格** | 一张大表按某一列拆开，比如每个部门一份、每人一份工资条 |
| **核对表格** | 两张表对一对：谁没交、谁多了、哪里对不上 |

几个工具能接起来用，比如：

- 各部门工资表 →（合并）→ 一张总表 →（按姓名拆分）→ 每人一份工资条 →（群发）→ 每人收到自己那份
- 全员名单 + 已交名单 →（核对）→ 还没交的人 →（群发）→ 催办邮件

- **不依赖任何网站或订阅**：程序在你自己电脑上跑，邮件从你自己的邮箱直接发出去。
- **不用另外装东西**：只要 Mac 上有 Python 3（下面有说明）。
- **隐私**：名单、表格、附件、授权码都只在这台电脑上。授权码存在 Mac 的「钥匙串」里。

## 第一次使用（只需要做一次）

### 1. 下载

打开 <https://github.com/Stella16872/-/archive/refs/heads/main.zip> 下载压缩包，双击解压，
把里面的 **「工具箱」文件夹** 拖到一个顺手的地方（比如「文稿」）。其余的文件用不到。

以后有新版本，同样从这个链接下载，用新的「工具箱」文件夹换掉旧的就行。
模板、发送记录、设置都存在 `~/工具箱数据` 里，换版本不会丢。

### 2. 确认有 Python 3

打开「终端」（在启动台里搜“终端”），输入下面这行，回车：

```
python3 --version
```

- 显示 `Python 3.x.x`：有了，跳过这步。
- 弹出窗口问要不要安装「命令行开发者工具」：点 **安装**，等它装完（几分钟）。

### 3. 邮箱开启 SMTP，拿到授权码

程序要替你登录邮箱发信，但**不用你的邮箱登录密码**，用的是一个专门的「授权码」。

**QQ 邮箱**
1. 电脑浏览器登录 mail.qq.com → 右上角「设置」→「账号」（新版界面是「账号与安全 → 安全设置」）
2. 找到「POP3/IMAP/SMTP/Exchange/CardDAV 服务」，开启「IMAP/SMTP 服务」（或 POP3/SMTP）
3. 按提示验证后，会给你一串 16 位的 **授权码**，复制下来

**Gmail**
1. 先开启两步验证：<https://myaccount.google.com/signinoptions/twosv>
2. 打开 <https://myaccount.google.com/apppasswords>，随便起个名字（比如“工具箱”），生成
3. 复制那串 16 位的 **应用专用密码**（中间的空格不用管）

**Outlook / Hotmail**：微软这几年在收紧第三方程序用密码登录，大概率登不上，建议用 QQ 邮箱或 Gmail。

## 每次使用

1. 双击「工具箱」文件夹里的 **双击打开.command**
   - 会弹出一个终端窗口，浏览器会自动打开工具箱页面
   - **用的时候不要关终端窗口**；用完点页面右上角「退出」，或者直接关掉终端窗口
2. 群发邮件页面上从上到下五步：

| 步骤 | 做什么 |
|---|---|
| 1 发件邮箱 | 填邮箱地址和授权码，点「保存并测试登录」。勾了「记住」的话，以后就不用再填 |
| 2 名单 | 把 Excel 拖进来 |
| 3 写邮件 | 写主题和正文。需要每人不一样的地方，点上面的「{列名}」按钮插入 |
| 4 检查和预览 | 一封封看，有问题的会标红；点「把这封发给自己测试」先看看真实效果 |
| 5 发送 | 设置间隔，点「开始发送」 |

第一次可以拿文件夹里的 **示例名单.xlsx** 练手：测试邮件只会发给你自己。

### 第一次打开时被 Mac 拦住了？

从网上下载的、没有经过苹果认证的程序，第一次打开都会被拦一下。

- 弹窗说「未打开」「Apple 无法验证……」，让你选「完成」或「移到废纸篓」：**点「完成」，别点废纸篓**。然后：
  1. 打开「系统设置 → 隐私与安全性」，一直往下拉到「安全性」
  2. 那里会写「已阻止“双击打开.command”……」，点旁边的 **仍要打开**，输入开机密码（或按指纹）
  3. 再双击一次「双击打开.command」，弹窗里点 **打开**（或「仍要打开」）。以后就不会再问了

  「仍要打开」按钮只在被拦之后一小时内出现；没看到的话，先再双击一次，再回去看。
- 不想点设置，也可以在「终端」里一次性解除：输入 `xattr -dr com.apple.quarantine `（最后有个空格），
  把整个「工具箱」文件夹拖进终端窗口，回车。之后双击就能直接打开
- 提示「没有权限」，或者双击之后用文本编辑打开了：打开「终端」，输入 `python3 `（后面有个空格），
  然后把「工具箱」文件夹里的 **app.py** 拖进终端窗口，回车。这个方法任何时候都能用

## 名单怎么准备

- **第一行是标题**（姓名、邮箱、公司……），下面**每个人一行**。表格顶上有一行大标题也没关系，会自动跳过
- 标题叫什么都行，邮件里用 `{标题}` 引用。叫「邮箱」「邮件」「Email」的那一列会被自动当成收件人
- 一个人要发给多个邮箱：同一格里用分号或逗号隔开
- 支持 Excel（.xlsx）和 CSV。Numbers 表格请先「文件 → 导出为 → Excel」；老的 .xls 请先另存为 .xlsx
- 数字和日期按 Excel 里**看到的样子**填进邮件（8,500.00、2026年10月31日），所以在 Excel 里把格式调好就行

## 模板写法

| 写法 | 意思 |
|---|---|
| `{姓名}` | 换成这一行「姓名」那一格 |
| `{公司|贵公司}` | 「公司」那格是空的时候，用“贵公司”代替 |
| `{{` 和 `}}` | 真的想在邮件里写花括号时用 |

收件人、抄送、密送、主题、正文、附件文件名规则，都可以用 `{列名}`。

**注意中文输入法**：中文状态下按 `{` 打出来的是「，`{姓名}` 会变成「姓名」，不会被替换。
最省事的办法是点页面上的按钮插入；写错了页面上也会提醒。

## 附件

文档（Word、Excel、PPT、PDF、Pages……）、图片、压缩包都可以，什么格式都行。

- **每封都带的附件**：点「添加文件」，所有人收到同样的文件（比如活动手册）
- **每个人不一样的附件**：把所有人的文件放进一个文件夹，点「选择文件夹」，再写「文件名规则」。
  选完文件夹，工具会看文件名的规律自动填一个规则，一般不用改：

| 文件夹里的文件 | 规则填 |
|---|---|
| `张三.pdf`、`李四.pdf` | `{姓名}` |
| `张三_合同.docx`、`张三_照片1.jpg`、`张三_照片2.jpg` | `{姓名}_*`（星号代表「后面随便什么」，一个人可以有好几个文件） |
| 每人一个小文件夹：`张三/合同.docx`、`张三/照片.jpg` | `{姓名}/*` |
| 表格里有一列「附件」直接写了文件名 | `{附件}`（一个人多个文件，用分号隔开） |

**建议文件名写成「名字_xxx」**，规则用 `{姓名}_*`。如果写成 `{姓名}*`（没有下划线），
「张三」会连「张三丰_合同.docx」也一起匹配上。

为了不发错，工具会检查这几件事：

- 某个人**找不到附件**：这一封标红、不会发，不会出现「发出去了但是忘了带附件」
- 同一份个人附件**会发给两个人**（比如上面张三和张三丰的情况）：标黄提醒
- 文件夹里有文件**没有对应的人**（比如表格里写「张三」，文件却叫「张叁.pdf」）：在第 4 步最上面提醒
- 第 4 步预览里**点附件就能打开看**，图片会直接显示缩略图，可以确认张三收到的确实是张三的照片

**iPhone 照片（.HEIC）会自动转成 JPG**：Windows 电脑常常打不开 HEIC，转成 JPG 谁都能看。
用的是 Mac 自带的转换功能，原图不会被改动。

**附件别太大**：大多数邮箱一封信的附件上限在 20～50 MB 左右（Gmail 是 25 MB）。
一封超过 18 MB 工具会提醒。照片多的话，可以先在「照片」App 里导出成小一点的尺寸，或者把照片打成压缩包。

## 发送时的保护

- **先测试**：第 4 步「把这封发给自己测试」，在自己邮箱里看看真实效果（附件、格式、手机上的样子）
- **一封封单独发**：每个人只看得到自己，不会出现一长串收件人
- **间隔**：默认每封隔 5 秒。发太快容易被邮箱当成垃圾邮件，或者被暂时限制
- **自动暂停**：登录失败、被邮箱限流、连着 3 封失败，都会自动暂停。处理好以后点「继续」，从停下的那封接着发
- **不怕重复**：发过的会记下来。30 天内对同一个人发同样主题的邮件，会提醒并默认跳过（发到一半关掉了，重新打开也不会重发）
- **发送记录**：每批都存一个表格（`~/工具箱数据/发送记录/`），谁成功、谁失败、为什么，一目了然。页面底部有「打开」按钮
- **防休眠**：发送过程中 Mac 不会自动睡眠
- 勾选「每封都密送一份给自己留底」，自己邮箱里会有每一封的备份（Gmail 本来就会自动存到「已发送」）

### 邮箱的每日上限

- Gmail 个人账号：每天大约 500 个收件人
- QQ 邮箱：也有每日和频率限制，具体数字没有公开。一次几十封通常没问题，上百封建议把间隔调大，或者分几天发
- 被限流了工具会自动暂停，等一段时间（几十分钟到第二天）再点「继续」

## 表格工具

三个工具都支持 Excel（.xlsx）和 CSV。练手可以用文件夹里的 **示例表格**：
`销售部.xlsx` + `技术部.xlsx` 试合并和拆分，`全员名单.xlsx` + `已交材料.xlsx` 试核对。

**几件自动处理好的事**

- **表格顶上的大标题**（比如「销售部 2026 年 9 月工资表」）会自动跳过，从真正的表头开始读。
  认错了的话，在「表头在」里选对的那一行
- **合并的单元格**：比如「组别」一列里好几行合成一格，每一行都会填上这个组别
- **「合计 / 小计」行**：合并、拆分的时候默认去掉（可以取消勾选）
- **数字和日期**：新表里还是数字和日期，格式也和原来一样（8,500.00 还是 8,500.00，能接着求和）

### 合并表格

1. 把几个文件一起拖进来。一个文件里有好几张工作表（比如 1 月到 12 月），在「工作表」里选「全部工作表」
2. 「对齐列」：按列名对齐，列的顺序不一样没关系。**标黄的行**是只有部分表格有的列——
   如果其实是同一个意思（比如一张表叫「名字」、另一张叫「姓名」），把右边「合并后叫」改成一样就会合成一列
3. 可选：加一列「来源」（每行来自哪个文件）、去掉完全重复的行
4. 「下载合并结果」存到「下载」文件夹；或者「接着拆分这张表」「接着拿去核对」直接用

### 拆分表格

1. 选表格，再选**按哪一列拆**（部门、姓名……），下面会列出会拆成几份、每份几行
2. 输出方式：
   - **每份一个文件**：放进一个文件夹（`~/工具箱数据/拆分结果/` 里），点「在访达中打开」就能看到。
     文件名可以改，比如 `{值}_9月工资条` → `张三_9月工资条.xlsx`
   - **一个文件**：每份一张工作表，下载到「下载」文件夹
3. 「用这些文件群发邮件」：拆好的文件直接变成群发里「每个人不一样的附件」，文件名规则也自动填好。
   如果这张表里有邮箱，名单也直接用它

### 核对表格

1. 表 A、表 B 各选一张。比如 A = 应该交的人（全员名单），B = 已经交了的人
2. 选**用哪一列来对应**（一般是姓名、工号、邮箱）。会自动猜，「姓名」和「名字」这种也认得出来。
   默认忽略空格、全角半角和大小写，「 张三 」和「张三」算同一个人
3. 结果分四类，点一下就能看：
   - **只在 A 里**：比如还没交的人
   - **只在 B 里**：比如不在名单上、却交了的人（可能名字写错了）
   - **内容不同**：两边都有，但某些列不一样（比如部门、金额对不上），会列出哪一列、各是什么
   - **两边一样**
4. 同一个人在一张表里出现了好几次、或者用来对应的那一格是空的，会提醒
5. 「下载核对结果」：一个 Excel，分「汇总 / 只在A里 / 只在B里 / 内容不同」几张表，不一样的格子标了黄色
6. 「给这 N 个人发邮件」：把这些人直接变成群发的名单，写好催办邮件就能发

## 常见问题

**登录失败**
QQ / 163 要用授权码，不是 QQ 密码；Gmail 要用应用专用密码。确认 SMTP 服务已经开启。
授权码可以随时在邮箱设置里重新生成，旧的会失效。

**连接超时**
开着代理 / 梯子的话先关掉再试；公司网络有时会拦截发邮件的端口。

**浏览器问「要上传这些文件吗」**
选附件文件夹时会出现。这里的「上传」只是交给你电脑上运行的工具箱，文件不会离开这台电脑。

**发出去的邮件在「已发送」里找不到**
程序是直接通过邮箱服务器发信的，QQ 邮箱不一定会存一份到「已发送」。需要留底就勾选「密送一份给自己」。

**换电脑 / 重装**
把「工具箱」文件夹拷过去就行。模板和发送记录在 `~/工具箱数据`（就是你的个人文件夹下面），也一起拷过去。

## 给以后改代码的人

| 文件 | 内容 |
|---|---|
| `app.py` | 本地网页服务（只监听 127.0.0.1）、发送任务、存设置和记录 |
| `mailer.py` | 模板填空、地址检查、附件匹配、拼邮件、SMTP 和错误翻译 |
| `sheets.py` | 读写 .xlsx / 读 .csv：找表头、合并单元格、按 Excel 的数字格式显示；写出的新表保留格式 |
| `tables.py` | 合并、拆分、核对的逻辑 |
| `tools_api.py` | 表格工具的网页接口 |
| `web/` | 页面：`index.html`、`style.css`，`common.js`（共用）、`app.js`（群发邮件）、`tools.js`（表格工具）；不依赖任何外部库 |
| `示例表格/` | 练手用的表格，测试也用它们 |
| `tests/` | `python3 tests/test_all.py` 跑全部测试（带一个假的邮件服务器，不会真发） |

只用 Python 自带的库，兼容 macOS 自带的 Python 3.9。
数据目录可以用环境变量 `TOOLBOX_DATA` 改。以后加新工具：在 `web/index.html` 顶栏加一个标签和一个
`<main class="page" id="tab-名字">`，逻辑写在 `web/tools.js`，接口加在 `tools_api.py` 的 `routes()` 里。
